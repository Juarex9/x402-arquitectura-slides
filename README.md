# x402 · Arquitectura de pagos HTTP-native

Presentación (HTML dinámico, un solo archivo offline) que explica qué es **x402**, el protocolo abierto de pagos sobre HTTP que revive el código `402 Payment Required`, y cómo funciona paso a paso: actores, flujo, headers v2 (`PAYMENT-REQUIRED`, `PAYMENT-SIGNATURE`, `PAYMENT-RESPONSE`), schemes y redes, facilitator, por qué Solana, casos de uso y cómo empezar.

Armada para el hackathon de **Superteam Argentina** (Road to Colosseum), 3 de octubre de 2026. Presenta: Agustín Juárez.

**En vivo:** https://x402-arquitectura-slides.vercel.app

## Atajos

| Tecla | Acción |
|---|---|
| `→` · `Espacio` · `PgDn` | siguiente (en el diagrama del flujo: próximo paso) |
| `←` · `PgUp` | anterior |
| `Home` / `End` | primera / última |
| `F` | pantalla completa |
| `O` | vista general |
| `R` | repetir el diagrama del flujo |
| `?` · `Esc` | ayuda / cerrar |
| clic / tap | izquierda = anterior · derecha = siguiente |
| swipe | en pantallas táctiles |

`#N` en la URL abre directo la diapositiva N (ej.: `#5` = el flujo).
